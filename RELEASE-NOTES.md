# Kane & Lynch 2 VR 0.6.26

This update fixes a SteamVR startup failure that could leave the game running
only in a desktop window. Automatic game audio routing to the headset is kept.

Install the complete update over your existing mod installation. Close the game
and mod settings window first. Your settings and game saves are kept. Do not
mix the launcher, VR hosts and mod DLL from different versions.

## Download

Use `KaneLynch2VR-0.6.26-Setup.exe`, or extract the Portable ZIP into its own
folder. Connect the headset, open **Kane & Lynch 2 VR Settings**, select the
connection you are using and choose **Save & play**.

## Before playing

This remains an early release for the **Windows Steam version, single player**.
Co-op and multiplayer have not been run or tested; their operation is not
guaranteed. Other game editions are unverified.

The game's 32-bit memory limits and runtime checks still constrain the mod.
Crashes can occur during mission loading and gameplay. Some scenery and textures
can disappear at particular distances. Cover movement, grips and scripted
interactions can be awkward. Two independent guns at once and automatic VR
scope zoom are not supported.

**For the required vault in the first mission:** hold **B** to enter cover,
release it, then **hold B again while moving the left stick** toward the obstacle.
Tap B to leave cover normally.

See [installation and renderers](INSTALLATION.md), [controls](CONTROLS.md) and
[known issues](KNOWN-ISSUES.md) for the full guide.
